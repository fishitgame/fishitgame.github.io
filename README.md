# fishitgame.github.io

Links page for Fish It! - https://fishitgame.github.io/

Plain HTML + CSS, no build, no JS. Push to `main` and Pages updates in a minute or so.

- `index.html` / `style.css` - the page
- `icons/`, `logo.png`, `favicon.png`, `og-image.png` - images
- `fonts/` - Fredoka + Nunito (OFL)

Note: there's a CSP meta tag in `index.html`, so everything has to be served from this repo
(no external scripts/styles/fonts).
